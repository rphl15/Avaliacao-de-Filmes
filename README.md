# Avaliação de Filmes

## Descrição do Projeto
Este projeto consiste na criação de uma empresa fictícia que utiliza análise de dados para avaliar a satisfação dos usuários em relação a filmes. O objetivo é analisar avaliações escritas por usuários e identificar padrões de sentimento, classificando-as como positivas ou negativas.

A análise permite entender melhor a percepção do público e gerar insights que podem auxiliar empresas do setor de entretenimento.

## Problema a ser Resolvido
Plataformas de filmes recebem milhares de avaliações de usuários todos os dias. Interpretar manualmente essas avaliações é difícil e demorado.

A proposta do projeto é desenvolver uma solução baseada em Ciência de Dados capaz de:

- Analisar automaticamente avaliações de filmes
- Identificar o sentimento das reviews
- Medir o nível de satisfação do público
- Encontrar padrões nas opiniões dos usuários

## Base de Dados Utilizada
IMDB Dataset of 50K Movie Reviews

Fonte: Kaggle  
https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews

## Objetivos

- Realizar análise exploratória dos dados
- Identificar padrões nas avaliações
- Aplicar técnicas de Processamento de Linguagem Natural (NLP)
- Construir um modelo para classificar sentimentos das avaliações
